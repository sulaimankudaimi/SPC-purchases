# دليل استخدام «منظومة إدارة المشتريات المحلية»

تطبيق سطح مكتب رسمي لدائرة الإمداد والتوريد — مديرية حقول دير الزور (الشركة السورية للبترول).

---

## 1. متطلبات التشغيل والتنصيب (Windows)

- **نظام التشغيل:** Windows 10 أو Windows 11 (معمارية 64-bit).
- **ملف التثبيت:** `منظومة المشتريات-Setup-0.0.0.exe`.
- **خطوات التنصيب:**
  1. انقر نقراً مزدوجاً فوق ملف المثبت.
  2. في حال ظهور تنبيه حماية Windows (SmartScreen) نظراً لعدم وجود توقيع رقمي تجاري (القرار D12):
     - انقر على **«مزيد من المعلومات» (More info)**.
     - ثم اختر **«تشغيل على أي حال» (Run anyway)**.
  3. سيقوم المثبت بإنشاء اختصار تلقائي على سطح المكتب وقائمة ابدأ باسم **«منظومة المشتريات»**.
- **التحديث:** يتم تثبيت أي إصدار جديد فوق الإصدار السابق مباشرة دون فقدان الإعدادات أو الجلسة أو بيانات السحابة.

---

## 2. تسجيل الدخول والمصادقة (D5)

1. أدخل البريد الإلكتروني وكلمة المرور المعتمدة لمسؤول المشتريات.
2. النظام محمي بالكامل عبر صلاحيات Row Level Security (RLS) ومستودع آمن.
3. لتسجيل الخروج، اضغط على زر الخروج أسفل الشريط الجانبي الأيمن بجوار بطاقة «مدير المشتريات».

---

## 3. الشاشات الرئيسية

### أ. لوحة التحكم والمؤشرات
- استعراض إجمالي طلبات الشراء، عدد المواد، القيمة التقديرية الكلية، والطلبات قيد الانتظار.
- رسوم بيانية تفاعلية (Recharts): التوزيع الشهري للإنفاق والطلبات، توزيع الحالات الخمس المعتمدة، وأعلى الجهات والأقسام.
- تصفية الإحصاءات بالفترة الزمنية (من / إلى) أو الفلاتر السريعة.

### ب. شاشة «طلب جديد»
- إدخال بيانات الطلب (الجهة الطالبة، القسم، مقدم الطلب، مكان وموعد التسليم، والعملة).
- إضافة المواد وتحديد الكمية والسعر، مع حساب فوري وإجباري للمجاميع دون أخطاء تقريب.
- حفظ وطباعة الاستمارة بصيغة PDF مطابقة للاستمارة الرسمية A4، وحفظ نسخة تلقائية في مجلد الأرشيف `Documents\ارشيف spc`.

### ج. شاشة «السجل»
- عرض كافة الطلبات السابقة مع البحث الفوري بالرمز أو الجهة أو الطالب أو المادة.
- فلاتر مخصصة للحالة والتاريخ.
- إمكانية تعديل الطلب، تغيير الحالة مع ذكر السبب الإلزامي، وإرفاق الفواتير.
- تصدير كامل السجل إلى ملف Excel متطابق بـ 17 عموداً A–Q ودمج الخلايا رأسياً.

### د. شاشة «الإعدادات»
- ضبط أسماء التواقيع الرسمية للاستمارة (مدير الإمداد، معاون المدير، رئيس قسم المشتريات، ورئيس قسم المالية).
- تحديد مجلد أرشيف الـ PDF المحلي والعملة الافتراضية.
- إدارة قوائم الوحدات والجهات المقترحة.
